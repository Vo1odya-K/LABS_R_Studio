
# Лабораторна робота №2 — розвідувальний аналіз даних (EDA)

## Тема

Аналіз вартості вживаних автомобілів.

## Автор

Каламаж Володимир, АтаВДвR-11.

## Мета роботи

Провести розвідувальний аналіз даних про вживані автомобілі,
дослідити розподіл цін та їхній зв'язок із характеристиками
автомобілів, сформулювати висновки й представити результати
у вигляді відтворюваної презентації.

## Джерело даних

Used Car Price Prediction Dataset — Kaggle.

https://www.kaggle.com/datasets/taeefnajib/used-car-price-prediction-dataset/data

- Кількість спостережень: 4009.
- Кількість змінних: 12.
- Роки випуску автомобілів: 1974–2024.
- Одиниця вимірювання ціни: USD.
- Одиниця вимірювання пробігу: милі.

## Дослідницькі запитання

1. Як розподіляються ціни вживаних автомобілів?
2. Як рік випуску пов'язаний із ціною автомобіля?
3. Чи існує зв'язок між пробігом і ціною?
4. Як відрізняються ціни залежно від марки та типу пального?
5. Як пов'язані з ціною історія ДТП, рік випуску та пробіг
   при спільному аналізі?

## Основні результати

- Після очищення збережено всі 4009 спостережень.
- Медіанна ціна автомобіля становить 31 000 USD.
- Середня ціна становить приблизно 44 553 USD.
- Розподіл цін має виражену правосторонню асиметрію.
- Кореляція Спірмена між ціною та роком випуску: 0,697.
- Кореляція Спірмена між ціною та пробігом: -0,755.
- Серед десяти найпоширеніших марок Porsche має
  найвищу медіанну ціну — 59 900 USD.
- Медіанна ціна автомобілів із повідомленнями про ДТП
  або пошкодження на 41,4% нижча порівняно з автомобілями
  без таких повідомлень.
- Спільний аналіз року випуску, пробігу та історії ДТП
  показав неоднорідність різниці цін між групами.

## Обмеження дослідження

- Вибірка не обов'язково репрезентує весь ринок автомобілів.
- Категорії мають неоднакову кількість спостережень.
- Частина категоріальних значень невідома.
- Потенційні викиди збережено в датасеті.
- Не враховано всі можливі чинники ціноутворення.
- Статистичні зв'язки не доводять причинно-наслідкових
  залежностей.

## Відтворення результатів

1. Відкрити проєкт у Positron.
2. Відкрити notebooks/EDA.ipynb.
3. Виконати всі комірки ноутбука послідовно.
4. Переконатися, що очищені дані, таблиці, графіки
   та метадані збережено у відповідних папках.
5. З кореневої папки проєкту виконати:

```powershell
Rscript reports/prepare_figures.R
quarto render reports/presentation.qmd
```

Для експорту PDF відкрити HTML-презентацію з параметром
?print-pdf та зберегти її через функцію друку браузера.
